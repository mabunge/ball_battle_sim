GitHub 업로드:
1. 새 저장소를 만듭니다.
2. 이 ZIP을 압축 해제합니다.
3. index.html, assets 폴더, .nojekyll을 저장소 최상단에 업로드합니다.
4. Settings > Pages > Build and deployment
5. Source: Deploy from a branch
6. Branch: main / /(root)
7. Save

주의:
- assets 폴더를 index.html과 같은 최상단 위치에 유지하세요.
- mot.mp3는 M.O.T 발동 시 9초 지점부터 재생됩니다.
